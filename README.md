# DreamTownIslandModKit

A personal modding project for Dream Town Island / 创造都市岛物语.

## Current status

- Game: Steam version
- Unity: 2021.3.11f1
- Runtime: IL2CPP
- Architecture: x86 / 32-bit
- Loader: BepInEx 6 Unity IL2CPP win-x86

## Goals

- Build a working BepInEx plugin
- Analyze resident / human systems
- Add tools for custom characters
- Explore texture replacement and character appearance customization

## Notes

This repository does not contain original game files.
Users must own the Steam version of the game.
